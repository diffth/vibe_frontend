# 웹리소스 리액트(React) 프로젝트 변환 작업계획서

본 계획서는 `org/` 폴더에 퍼블리싱된 기존 HTML/CSS/JS 웹소스를 분석하여, Vite 기반의 React, TypeScript, styled-components 환경으로 마이그레이션하기 위한 작업 계획을 정의합니다.

---

## 1. 원본 소스 분석 결과

### A. 마크업 및 디자인 구조 (`index.html`)
* **레이아웃**: 전체 화면을 감싸는 `.wrapper` 내부에 `#header`, `#main`, `#footer`로 구성되어 있습니다.
* **헤더 (`#header`)**:
  * 로고 (`img/logo.png`) 및 GNB 메뉴(회사소개, 제품소개, 시공사례, 견적문의, 고객센터)로 구성됩니다.
  * 서브메뉴(`.depth2`)가 절대 좌표(`Abs`)로 포함되어 마우스 호버 시 노출됩니다.
  * 우측 상단에 햄버거 메뉴 버튼(`.allmenu`)이 있어 클릭 시 전체 메뉴(`.allgnb`)가 토글됩니다.
* **메인 (`#main`)**:
  * **Visual Section**: `.swiper1` 컨테이너 내 5개의 메인 배러 슬라이드가 존재하며, 텍스트 효과와 함께 슬라이드가 전환됩니다.
  * **Product Section**: `.swiper2` 컨테이너로 구성된 원형 아이콘 링크 슬라이더가 위치하며, 5개씩 화면에 표시됩니다.
  * **Construction Case Section**: 4개의 최근 시공 사례 이미지가 카드 형태로 배열되어 있습니다.
  * **BBS Section**: 공지사항 게시판 목록, 고객센터 연락 정보, 견적문의 바로가기로 삼단 레이아웃을 이룹니다.
* **푸터 (`#footer`)**:
  * 기업 정보(주소, 연락처, 대표자 등), 저작권 표시, 푸터 로고 및 개인정보취급방침 링크가 포함되어 있습니다.

### B. 스타일시트 분석 (`css/`)
* **`reset.css`**: 브라우저 기본 스타일 초기화.
* **`common.css`**: 폰트 정의(Raleway 구글 웹폰트 포함), 공통 레이아웃 유틸리티 클래스(예: `.Abs`, `.clear`, `.size` 등) 정의.
* **`content.css`**: 메인 페이지의 배너 이미지(background-image), Product 원형 썸네일(background-image) 및 세부 컴포넌트의 스타일 정의.
* **`swiper.css`**: Swiper 슬라이더 디자인 스타일 정의.

### C. 자바스크립트 및 인터랙션 분석 (`js/script.js`)
* **메뉴 호버 액션**: GNB 1차 메뉴 호버 시, 해당 1차 메뉴의 2차 메뉴(`.depth2`)를 jQuery `slideDown()`/`slideUp()` 메서드로 표시/숨김 처리.
* **전체메뉴 토글**: `.allmenu` 버튼 클릭 시 `.allgnb` 영역을 `show()`/`hide()` 처리하고 `.allmenu`에 `.on` 클래스를 추가/제거.
* **Swiper 1 (메인 배너)**: 페이징 네비게이션 및 이전/다음 버튼이 탑재된 루프(Loop)형 슬라이더.
* **Swiper 2 (상품 슬라이더)**: 5개의 슬라이드를 동시에 노출하며 간격 30px을 가지는 루프형 슬라이더.

## 2. 기술 스택 및 환경 정보

* **프레임워크**: React (Vite 기반 빌드)
* **개발 언어**: TypeScript
* **라우터**: React Router DOM (경로: `/`)
* **스타일**: `styled-components` (CSS-in-JS)
* **슬라이더 라이브러리**: `swiper` (React 전용 컴포넌트 API 활용)

## 3. 디렉토리 구조 및 컴포넌트 설계안

변환 이후 적용할 React 프로젝트의 권장 폴더 구조는 다음과 같습니다.

```text
src/
├── assets/                  # 정적 이미지 및 리소스 (Vite를 통한 컴포넌트 내 import 대상)
├── components/              # 재사용 및 공통 컴포넌트
│   ├── Layout.tsx           # 전역 레이아웃 (Header + Footer + Main content)
│   ├── Header.tsx           # 공통 헤더 컴포넌트 (GNB, 전체메뉴 토글 state 내장)
│   └── Footer.tsx           # 공통 푸터 컴포넌트
├── pages/                   # 라우터 페이지 컴포넌트
│   └── Main.tsx             # 메인 페이지 (index.html 본문 마이그레이션)
├── styles/                  # 스타일 관련 폴더
│   ├── GlobalStyle.ts       # reset.css 및 common.css를 병합한 전역 styled-components
│   └── theme.ts             # 색상값, 미디어 쿼리 등 공통 Theme 정의
├── App.tsx                  # 라우팅 및 App 구성 요소
└── main.tsx                 # React DOM 렌더링 시작점
```

## 4. 단계별 작업 계획

### [Phase 1] 환경 설정 및 개발 환경 준비
1. **React Vite 프로젝트 생성**
   * Target Path: `D:\vibe_frontend\ex3`
   * TypeScript 템플릿 사용
2. **필요 패키지 설치**
   * `styled-components`, `@types/styled-components`
   * `react-router-dom`
   * `swiper` (React 용)
3. **정적 리소스 복사**
   * `org/img/` 하위의 모든 이미지 파일을 React 프로젝트의 `public/img/` 또는 `src/assets/images/`로 이동.
   * `background-image`에서 직접 참조하는 리소스의 경로 매핑 작업 수행.

### [Phase 2] 스타일 시스템 및 전역 레이아웃 구현
1. **전역 스타일 (`src/styles/GlobalStyle.ts`) 구축**
   * `org/css/reset.css`와 `org/css/common.css` 분석 결과를 바탕으로 `createGlobalStyle` 정의.
   * Raleway 및 한글 웹폰트 추가.
2. **공통 컴포넌트 분리 및 구현**
   * **Header Component (`src/components/Header.tsx`)**
     * jQuery 마우스오버/아웃 이벤트를 React `onMouseEnter`/`onMouseLeave` 및 `useState` 상태 관리로 대체.
     * 전체메뉴 토글 상태 변수(`isOpenAllMenu`)를 활용하여 `.allgnb` 노출 조건부 렌더링 구현.
     * 로고 및 메뉴 링크 구성.
   * **Footer Component (`src/components/Footer.tsx`)**
     * 주소 및 사업자 정보 컴포넌트화.
   * **Layout Component (`src/components/Layout.tsx`)**
     * Header와 Footer를 배치하고 `<Outlet />`을 통해 페이지별 컴포넌트가 마운트되도록 구성.

### [Phase 3] 메인 페이지 콘텐츠 변환 및 인터랙션 구현 (`src/pages/Main.tsx`)
1. **styled-components 기반 CSS 마이그레이션**
   * `content.css`에 기재된 CSS 룰을 각 섹션별 styled-components 단위로 파편화하여 구현.
   * 배경 이미지 경로(`background-image: url(...)`)를 React에 알맞게 매핑.
2. **메인 Visual Swiper 적용**
   * `swiper/react` 라이브러리의 `<Swiper>` 및 `<SwiperSlide>` 컴포넌트 적용.
   * Pagination 및 Navigation 모듈 임포트 후 `index.html` 구조에 맞추어 마운트.
3. **Product Swiper 적용**
   * `slidesPerView: 5`, `spaceBetween: 30`, `loop: true` 설정이 반영된 React Swiper 구현.
   * 아이콘 및 텍스트 레이아웃 변환.
4. **시공사례(Construction Case) 및 BBS 섹션 구조화**
   * 정적 HTML 마크업을 JSX 형식에 맞춰 클린 코드로 정리.

### [Phase 4] 라우팅 구성 및 검증
1. **App.tsx 설정**
   * `BrowserRouter`, `Routes`, `Route`를 활용하여 `/` 경로에 `Main` 페이지를 렌더링하도록 셋업.
2. **동작 검증 및 빌드 테스트**
   * 로컬 개발 서버 실행 (`npm run dev`) 후 UI 레이아웃 및 JS 슬라이더 작동 여부 확인.
   * 렌더링 깨짐, 콘솔 에러 유무 확인.
